# Kino na Klik

Prosta strona do rezerwacji miejsc w kinie. Projekt na zaliczenie z zarządzania projektem wdrożeniowym.

## Co będzie można zrobić

- zobaczyć repertuar i wybrać seans,
- wybrać wolne miejsce na sali,
- podać imię i zatwierdzić rezerwację,
- otrzymać numer rezerwacji,
- zobaczyć, które miejsca są już zajęte.

Rezerwacje będą zapisywane w pliku JSON, bez bazy danych.

## Technologie

HTML, CSS i PHP 8.1 lub nowsze.

## Uruchomienie

Po dodaniu plików aplikacji:

1. Zainstaluj PHP 8.1 lub nowsze.
2. W katalogu projektu uruchom `php -S localhost:8000`.
3. Otwórz `http://localhost:8000` w przeglądarce.
